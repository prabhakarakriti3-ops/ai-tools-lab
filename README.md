AI Tools Lab
📌 Project Description

AI Tools Lab is a beginner-friendly Python project that contains useful sorting algorithms and utility functions. The project is designed to help students understand basic Python programming concepts and practice writing reusable functions.

Features
Simple sorting algorithms
Useful utility functions
Beginner-friendly Python code
Easy-to-understand examples
Organized project structure
🚀 Installation
1. Clone the Repository
git clone https://github.com/your-username/AI-Tools-Lab.git
2. Open the Project Folder
cd AI-Tools-Lab
3. Make Sure Python is Installed

Check your Python version:

python --version

If Python is installed correctly, its version number will be displayed.

💻 Usage

You can run the Python programs directly from the terminal.

Example 1: Sorting a List
from sorting import bubble_sort

numbers = [5, 2, 8, 1, 3]

result = bubble_sort(numbers)

print(result)

Output:

[1, 2, 3, 5, 8]
Example 2: Using a Utility Function
from utilities import is_even

number = 10

print(is_even(number))

Output:

True
